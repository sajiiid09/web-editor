## Video Editor

A React/Next.js video editor MVP focused on the core editing loop: import media, arrange it on a timeline, preview the composition, save local project state, and export.

## MVP scope

- 🎬 Timeline editing for arranging uploaded media and built-in assets.
- 📁 Local project create/load/autosave using browser storage.
- ⬆️ Upload video, image, and audio assets, then add them to the timeline.
- 📝 Add and edit basic text elements.
- 🖼️ Add stock images/videos and simple shape elements.
- 🔀 Add supported transitions.
- 📐 Resize the composition between common aspect ratios.
- 👀 Preview edits in the editor.
- 📤 Export from the current editor state.

## Not in the MVP

- Captions generation/editing is hidden for now.
- AI voice generation is hidden for now.
- Sharing/collaboration is hidden until projects have real server-side ownership.
- Local project persistence is browser-only and is not a production backup/sync system.
